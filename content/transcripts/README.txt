Transcripts normally come straight from Captivate through the podcast feed.
To override one, or add one Captivate doesn't have, save a file here named
after the episode's web address ending, for example:

  a-barber-a-spider-pepe-the-squirrel.txt

Accepted: .txt or .md (blank line between paragraphs, "Name: text" for
speakers), .html, .srt, .vtt
